# Adaptive MTP+Vegas gamma screening with full-vocabulary entropy

> Historical controller data. These runs still used forced gamma-10
> calibration and CPU entropy. The current implementation removed the forced
> calibration, added a measured dense-MTP fallback, and computes entropy on the
> backend. See [`../../ADAPTIVE_GAMMA.md`](../../ADAPTIVE_GAMMA.md) and the
> branch closeout in [`../../README.md`](../../README.md).

## Scope

This is the paper-faithful rerun of the SparseSpec-L-style adaptive speculation
policy in `llama-vegas`. Entropy is computed over the MTP model's full output
distribution before sampler truncation. Every run uses MTP+Vegas, candidates
gamma 1 through 10, entropy EMA beta 0.9, greedy sampling, 128 generated
tokens, batch one, full CUDA offload, and an RTX 3090. The first speculative
cycle uses gamma 10 to seed the request-local entropy and cost estimates. Later
cycles maximize:

```text
(1 + sum_m product_i p_i) / (measured MTP+Vegas draft cost + measured verification cost)
```

The Qwen runs use the resized OpenCode conversation fixture. Gemma uses the
resized Codex conversation fixture. Per the requested reduced scope, only the
eight adaptive configurations were run. There are no contemporaneous
fixed-gamma or dense-MTP controls, so these results do not establish a speedup
or regression relative to a baseline. Each cell has one repetition.

## Interpretation

The controller does not reduce to one universal gamma. Qwen27 contracts to
gamma 1 at both lengths. Gemma uses gamma 1-3 at 32K, but its acceptance on the
64K prompt collapses and the controller contracts to gamma 1. Qwen35 is
context-dependent: both 32K cache layouts choose gamma 1 after calibration,
while the 64K runs primarily choose gamma 4 for q8/turbo4 and gamma 3 for
q8/q4.

Full-vocabulary entropy is materially more expensive in this implementation
than the paper's reported controller overhead. It requires a CPU log-sum-exp
over the entire vocabulary for every proposed token because the existing
greedy MTP sampler otherwise truncates candidates before the observer sees
them. Relative to the preliminary top-10 screening, measured draft time grew
by roughly 25-85 ms in seven directly comparable cells and 130 ms in the
Qwen35 q8/turbo4 64K cell. The selected gamma pattern was mostly stable, but
throughput fell by 0.8-9.2% in this paired screening. A production version
should fuse or reuse entropy computation rather than treating this exact
implementation as overhead-free.

## Memory note

Qwen35 at 64K initially OOMed with context capacity 73,728 and ubatch 128. Both
cache layouts were run successfully with the same 65,536-token active prompt,
context capacity 66,048, and ubatch/MTP ubatch 64. Other cells used capacities
40,960 or 73,728 and ubatch 128.
