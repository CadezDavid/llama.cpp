# Preliminary adaptive MTP+Vegas gamma screening

> Historical controller data. These runs used a forced gamma-10 calibration
> and no dense-MTP action. The current implementation removed that calibration,
> added a measured dense-MTP fallback, and moved entropy computation to the
> backend. See [`../../ADAPTIVE_GAMMA.md`](../../ADAPTIVE_GAMMA.md) and the
> branch closeout in [`../../README.md`](../../README.md).

## Scope

This is the preliminary one-pass screening of the SparseSpec-L-style adaptive
speculation policy in `llama-vegas`. Entropy in these runs was normalized over
the sampler's top-10 candidates rather than the full output distribution used
by the paper. The paper-faithful rerun superseding these numbers is in
`../adaptive-gamma-full-entropy-2026-08-05/`.

Every run uses MTP+Vegas, candidates gamma 1 through
10, entropy EMA beta 0.9, greedy sampling, 128 generated tokens, batch one,
full CUDA offload, and an RTX 3090. The first speculative cycle uses gamma 10
to seed the request-local entropy and cost estimates. Later cycles maximize:

```text
(1 + sum_m product_i p_i) / (measured MTP+Vegas draft cost + measured verification cost)
```

The Qwen runs use the resized OpenCode conversation fixture. Gemma uses the
resized Codex conversation fixture. Per the requested reduced scope, no
contemporaneous fixed-gamma or dense-MTP controls were run, so these results do
not establish speedup or regression relative to a baseline.

## Interpretation

The controller does not reduce to one universal gamma. Qwen27 strongly prefers
gamma 1 at both lengths. Gemma moves among gamma 1-3 at 32K, but its acceptance
on this particular resized prompt collapses at 64K and the controller contracts
to gamma 1. Qwen35 is the interesting counterexample: both 64K cache layouts
choose longer blocks, primarily gamma 4 for q8/turbo4 and gamma 3 for q8/q4.

High aggregate acceptance does not by itself force a long block. Qwen35
q8/turbo4 at 32K accepts 78.9% of proposed tokens but selects gamma 1 after
calibration because the request-local entropy and measured cost objective rates
additional positions as uneconomic. Conversely, the 64K q8/turbo4 run selects
gamma 4 despite lower aggregate acceptance because the longer-context draft
savings change the measured cost balance.

## Memory note

Qwen35 q8/turbo4 at 64K initially OOMed with the matrix default context capacity
73,728 and ubatch 128. It was rerun successfully with the same 65,536-token
active prompt, context capacity 66,048, and ubatch/MTP ubatch 64. The q8/q4 64K
run used the same memory-tight settings. Other cells used capacities 40,960 or
73,728 and ubatch 128.
